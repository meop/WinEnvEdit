Privacy policy

WinEnvEdit works locally with your Windows environment variables. It does not require an account or send your environment-variable values to the publisher.

Information used by the application

The app reads Windows user, system and session environment variables to display them. When you save, it writes the changes you selected to Windows. It reads and writes local files you select for import and export, and uses the clipboard when you request copy or paste.

The application does not include publisher-operated analytics, advertising, cloud synchronization or a telemetry service. Exported files and clipboard contents may include sensitive information; you control where you store or share them.

Other services

This website is hosted by GitHub Pages. Downloads, source code and support issues are hosted on GitHub. Those services process information under GitHub's privacy statement. GitHub issues are public.

If you obtain the app through a package manager or the Microsoft Store when available, that service handles downloads, updates and any associated account information under its own policies. This website contains no publisher-added analytics or advertising scripts.

Removal and contact

Uninstalling WinEnvEdit does not undo environment-variable changes you intentionally saved. You can change or remove those values using Windows or another environment editor. Delete exported backups yourself when you no longer need them.

For privacy questions, use the support page. Do not post secrets in a public issue. This policy will be updated if the application's data handling changes.
