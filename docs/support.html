WinEnvEdit support

Documentation and issue reports are maintained in the project's public GitHub repository.

Report an issue or request help

Before opening an issue

Read the usage guide and check whether the problem is already reported. Include your app version, Windows version, processor architecture, installation method, steps to reproduce and the error text.

Environment variables can contain passwords, API keys and private paths. Remove sensitive values from screenshots, exported files and issue reports. GitHub issues are public.

Common questions

Why does a system save ask for permission?

System variables apply to the machine and require administrator rights. User variables do not. Windows handles consent through its normal UAC prompt.

Why doesn't a changed value appear in another app?

Already running processes can keep an older environment. Close and reopen the affected app or terminal. Some changes may require signing out and back in.

How do I protect my current settings?

Use Export before editing and save the resulting TOML backup somewhere private. Review imported values before saving them.

Support expectations

WinEnvEdit is a community-maintained, open-source utility. Support is provided through GitHub issues; there is no guaranteed response time or paid support agreement.
